# Sample cases

These five excerpts are **synthetic**. They are not VitalDB recordings and they
are not patient data. They match a VitalDB-like schema (ABP waveform, SpO2,
BIS-like depth proxy, infusion rate, effect-site concentration) so the
harnesses measure real SQI and PK/PD behavior without redistributing corpus
bytes.

VitalDB redistribution terms conflict across official sources (PhysioNet
mirror CC BY 4.0 vs vitaldb.net CC BY-NC-SA 4.0 + DUA). Because excerpts
cannot be confirmed as redistributable into this MIT repository, Phase 0
does not include VitalDB bytes. Do not download the full VitalDB corpus
here. See `docs/DATA.md`.

Each file pair is `<1 MB`. Generated by `data/sample/build.py` (seed 0).

| File | Why it is here |
| --- | --- |
| `clean.npz` + `.json` | Full coverage. SQI usable fraction is high on every signal. |
| `artifact.npz` + `.json` | Arterial flush (square ~300 mmHg) then overdamped plateau at 42 mmHg. SQI must reject; must not call hypotension. |
| `dropout.npz` + `.json` | 20 s NaN gap on ABP and SpO2. Gaps reported, never interpolated. |
| `bolus.npz` + `.json` | 80 mg propofol bolus. Infusion rate and Ce diverge. Depth proxy tracks Ce. |
| `no-label.npz` + `.json` | No usable BIS / awareness label. Excluded from training. |

`case_index.json` is a 200-row synthetic stand-in for a VitalDB-scale label
audit. `manifest.json` is what `or-signals demo-plan` prints.

Label proxies (BIS-like) are not awareness labels. This is research, not a
monitor.
