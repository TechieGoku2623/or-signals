# signal_quality

## What is measured

Fraction of each of the five sample cases that remains usable after artifact
rejection, per signal type (ABP, SpO2, BIS when present).

## Why it decides something

If the quality module treats an arterial flush as hypotension, or interpolates
a dropout, later models learn artifacts. This harness decides whether the
Phase 0 SQI rules are strict enough to ship as the default gate.

## How to run

```bash
uv run python research/phase0/signal_quality/run.py
```

Seed: 0. Cases are generated by `data/sample/build.py`.
